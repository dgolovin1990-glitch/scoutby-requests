# СтройГрад — обращения жителей

Два связанных учебных кабинета: управляющая компания и житель. Общая очередь, назначение подразделений, статусы и история действий. Только вымышленные данные.

## Открыть приложения

- [Кабинет управляющей компании](https://scoutby-research-uk-oct26.dmitryga.chatgpt.site/uk.html)
- [Кабинет жильца](https://scoutby-research-uk-oct26.dmitryga.chatgpt.site/resident.html)
- [Категории и адресаты](https://scoutby-research-uk-oct26.dmitryga.chatgpt.site/uk.html#catalog)

Оба кабинета доступны без учётной записи GPT/Google. Код переносится в этот репозиторий вместе с инструкциями и историей версий. Работающий сервер и общая база пока остаются на существующем публичном хостинге.
