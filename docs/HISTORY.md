# Происхождение и история

Проект создан 20.10.2026 для задания 2 «Исследование» пакета «Скаутби» и затем расширен до двух связанных кабинетов.

Исходные версии:
1. `a1ce4e0c61f456439c822180b4e43b9384c1adaf` — исследование 150 вымышленных обращений, статический публичный интерфейс.
2. `c02a44dd64e2b51cc58cf366006cff2aaf2755ea` — кабинеты УК/жильца, общая D1-база, статусы и история действий.

GitHub-история содержит импортированные снимки этих версий и последующую подготовку запуска. При импорте через подключённый GitHub создаются новые SHA; исходные Git-объекты с точными старыми SHA сохранены в `source-history.bundle`.

Восстановление исходной Git-истории:

```sh
git clone docs/source-history.bundle source-history
```

Bundle содержит только исходные Git-коммиты, а не рабочие секреты, не локальную базу и не чат. Переписка и подробный журнал ошибок остаются в локальном пакете сдачи. В публичные данные удалены подписи и номера квартир, адреса заменены кодами домов. Учебная очередь не является независимым эталоном качества ИИ.
